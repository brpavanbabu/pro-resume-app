# ProResume - Professional Resume Builder

A modern, interactive resume builder built with React and Vite.

## Features

- ✨ Clean, professional resume templates
- 📝 Easy-to-use form interface
- 👁️ Live preview of your resume
- 📄 PDF export functionality
- 🎨 Modern, responsive design

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Clone this repository
2. Install dependencies:

```bash
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

Open your browser and navigate to `http://localhost:5173`

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Deployment to Vercel

1. Push this repository to GitHub
2. Go to [Vercel.com](https://vercel.com) and sign in
3. Click "Add New..." → "Project"
4. Import your GitHub repository
5. Vercel will auto-detect the Vite framework
6. Click "Deploy"

That's it! Your resume builder will be live in about a minute.

## Usage

1. Fill in your personal information in the form
2. Add your work experience, education, skills, and projects
3. Click "Preview" to see your resume
4. Click "Download PDF" to export your resume

## Technologies Used

- React 18
- Vite
- Lucide React (icons)
